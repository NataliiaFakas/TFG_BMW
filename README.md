## Evaluación de modelos de predicción de ventas de BMW en Europa

En este repositorio se encuentra el proyecto completo desarrollado para la **comparación de diferentes modelos de Machine Learning aplicados a la predicción de ventas de BMW en Europa**.

Los modelos evaluados son **Baseline Naive**, utilizado como modelo de referencia, **Random Forest**, **Ridge Regression** y **Gradient Boosting**.

Una de las principales particularidades del estudio es el uso de **datasets con un número reducido de observaciones**, lo que condiciona la metodología empleada y requiere adaptar tanto la partición de los datos como el proceso de evaluación y comparación de los modelos.
